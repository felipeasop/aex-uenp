# 🧶 Lua e Flor

**Lua e Flor** é um projeto de loja de bonecas de tricô artesanais, desenvolvido em Python utilizando o framework Django. O sistema utiliza o Django Admin para facilitar o gerenciamento dos produtos e das informações da loja.

## ✨ Funcionalidades

- 🧸 Cadastro e gerenciamento de bonecas artesanais.
- 🧵 Organização das informações dos produtos.
- 🛠️ Painel administrativo integrado com Django Admin.
- 📦 Gerenciamento dos produtos por meio de uma interface administrativa.

## 🚀 Tecnologias utilizadas

- **Python** — linguagem de programação.
- **Django** — framework web utilizado no desenvolvimento.
- **Django Admin** — painel administrativo para gerenciamento dos dados.

## 🎯 Objetivo do projeto

O objetivo do Lua e Flor é facilitar o gerenciamento de uma loja de bonecas de tricô artesanais, oferecendo uma estrutura para cadastrar e administrar os produtos.
