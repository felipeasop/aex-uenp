\section{Introdução e Objetivo}

O objetivo deste projeto foi transformar a modelagem de sistema desenvolvida em Engenharia de Software II em um sistema web funcional para a \textbf{Loja Lua e Flor}, atendendo aos requisitos da disciplina de Programação para Internet. A aplicação contempla as regras de negócio do artesanato em crochê, dividindo as aquisições em dois tipos:
\begin{enumerate}
    \item \textbf{Pronta-Entrega:} Itens estocados que decrementam o estoque no momento da compra.
    \item \textbf{Sob Encomenda:} Peças sob demanda vinculadas a ciclos limitados de produção.
\end{enumerate}

\section{Tecnologias e Arquitetura do Sistema}

O sistema foi estruturado utilizando o padrão \textbf{MVT (Model-View-Template)} do Django, que separa a estrutura dos dados (Models), a lógica de controle (Views) e a interface visual (Templates).

O projeto foi dividido em três módulos principais (\textit{Django Apps}) para manter o código organizado:
\begin{itemize}
    \item \texttt{usuarios}: Gerencia o cadastro, login e controle de papéis (clientes e administradores).
    \item \texttt{catalogo}: Gerencia os produtos, categorias e a verificação de disponibilidade.
    \item \texttt{vendas}: Controla o carrinho de compras, finalização de pedidos e o estoque.
\end{itemize}

\section{Modelagem e Implementação}

Abaixo estão os principais trechos de código que sustentam o funcionamento do sistema a partir do diagrama de classes planejado.

\subsection{Modelo de Usuário (\texttt{apps.usuarios})}
Permite diferenciar clientes de administradores/artesãos e operadores conforme a modelagem de atores:
\begin{lstlisting}[language=Python]
from django.db import models
from django.contrib.auth.models import AbstractUser

class Usuario(AbstractUser):
    # Tipos de perfis conforme especificacao de atores da modelagem
    class Tipo(models.TextChoices):
        ADMIN = 'ADMIN', 'Administrador'
        OPERADOR = 'OPERADOR', 'Operador'
        CLIENTE = 'CLIENTE', 'Cliente'

    tipo = models.CharField(
        max_length=20,
        choices=Tipo.choices,
        default=Tipo.CLIENTE,
        verbose_name='Tipo de Perfil'
    )
    telefone = models.CharField(max_length=25, blank=True)
    data_nascimento = models.DateField(null=True, blank=True)

    # Identificadores de papeis para controle de acesso (Req. F13 / NF02)
    @property
    def is_administrador(self):
        return self.tipo == self.Tipo.ADMIN or self.is_superuser

    @property
    def is_operador(self):
        return self.tipo == self.Tipo.OPERADOR
\end{lstlisting}

\subsection{Modelo de Produto e Regra de Disponibilidade (\texttt{apps.catalogo})}
Calcula dinamicamente se o produto pode ser comprado a pronta-entrega, encomendado ou se está esgotado:
\begin{lstlisting}[language=Python]
class Produto(models.Model):
    nome = models.CharField(max_length=200, verbose_name='Nome do Fofurinho')
    descricao = models.TextField()
    preco = models.DecimalField(max_digits=10, decimal_places=2)
    estoque = models.PositiveIntegerField(default=0)
    tempo_estimado = models.PositiveIntegerField(default=10) # Dias de confeccao
    ciclo_encomenda = models.ForeignKey('CicloEncomenda', null=True, blank=True, on_delete=models.SET_NULL)

    @property
    def status_disponibilidade(self):
        # 1. Se ha pecas em estoque, entrega imediata (Req. F29)
        if self.estoque > 0:
            return 'disponivel'
        # 2. Sem estoque: verifica vagas no ciclo de encomendas (Req. F30)
        ciclo = self.ciclo_encomenda or CicloEncomenda.objects.filter(is_aberto=True).first()
        if ciclo and ciclo.checar_limite():
            return 'encomenda'
        # 3. Sem estoque e sem vagas no ciclo: esgotado (Req. F31)
        return 'esgotado'
\end{lstlisting}

\subsection{Controle de Vagas do Ciclo de Encomendas (\texttt{apps.catalogo})}
Garante a integridade do teto de capacidade artesanal, impedindo extrapolações do limite máximo:
\begin{lstlisting}[language=Python]
class CicloEncomenda(models.Model):
    nome = models.CharField(max_length=100, default='Ciclo Atual')
    limite_maximo = models.PositiveIntegerField(default=10) # Teto definido pela artesã (Req. F27)
    quantidade_atual = models.PositiveIntegerField(default=0)
    is_aberto = models.BooleanField(default=True)

    def checar_limite(self):
        """Verifica se o ciclo ainda possui vagas abertas."""
        return self.is_aberto and (self.quantidade_atual < self.limite_maximo)

    def vagas_disponiveis(self):
        """Calcula o saldo restante de pecas que podem ser aceitas."""
        if not self.is_aberto:
            return 0
        return max(0, self.limite_maximo - self.quantidade_atual)

    def cabe_encomenda(self, quantidade=1):
        """Garante que a adicao em lote nao ultrapasse o teto maximo."""
        return self.is_aberto and (self.quantidade_atual + quantidade <= self.limite_maximo)

    def adicionar_encomenda(self, quantidade=1):
        """Incrementa o contador de producao do ciclo ativo."""
        self.quantidade_atual += quantidade
        self.save()
\end{lstlisting}

\subsection{Controle de Vendas, Carrinho e Fila de Produção (\texttt{apps.vendas})}
Gerencia o fluxo do carrinho, validação de regras de ciclo no checkout e inserção na fila de espera:
\begin{lstlisting}[language=Python]
@login_required(login_url='usuarios:login')
def checkout_view(request):
    carrinho = obter_carrinho(request)
    
    if request.method == 'POST':
        # 1. Validacao rigorosa do teto do ciclo antes de efetivar o pedido
        itens_carrinho = carrinho.itens.select_related('produto', 'produto__ciclo_encomenda')
        for item_cart in itens_carrinho:
            if item_cart.produto.status_disponibilidade == 'encomenda':
                ciclo = item_cart.produto.ciclo_encomenda or CicloEncomenda.objects.filter(is_aberto=True).first()
                if ciclo and not ciclo.cabe_encomenda(item_cart.quantidade):
                    messages.error(request, f'Limite excedido no ciclo! Vagas restantes: {ciclo.vagas_disponiveis()}')
                    return redirect('vendas:carrinho')

        # 2. Criacao do registro formal do Pedido (Req. F09)
        pedido = Pedido.objects.create(
            numero=gerar_numero_pedido(),
            cliente=request.user,
            subtotal=carrinho.calcular_subtotal(),
            valor_total=carrinho.calcular_total(),
            metodo_pagamento=request.POST.get('metodo_pagamento')
        )

        # 3. Baixa em estoque ou encaminhamento para a Fila de Producao (Req. F33/F34)
        for item_cart in itens_carrinho:
            is_encomenda = (item_cart.produto.status_disponibilidade == 'encomenda')
            item_pedido = ItemPedido.objects.create(
                pedido=pedido, produto=item_cart.produto,
                quantidade=item_cart.quantidade, preco_unitario=item_cart.produto.preco,
                is_encomenda=is_encomenda
            )
            if is_encomenda:
                ciclo.adicionar_encomenda(item_cart.quantidade)
                # Aloca na fila com calculo acumulado de dias de confeccao
                FilaProducao.objects.create(
                    item_pedido=item_pedido,
                    posicao=FilaProducao.objects.count() + 1,
                    tempo_estimado_dias=item_cart.produto.tempo_estimado * item_cart.quantidade
                )
            else:
                item_cart.produto.estoque -= item_cart.quantidade
                item_cart.produto.save()

        carrinho.limpar()
        return redirect('vendas:confirmacao', pedido_id=pedido.id)
\end{lstlisting}
